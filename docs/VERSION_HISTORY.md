# OpenRF Platform v0.8.0 — Final Development Release

Stable optimized baseline release.

## Native RX protocols
- EV1527 / HS1527 / Princeton-compatible OOK PWM
- PT2262 / PT2272-compatible tri-state OOK PWM

## Unchanged subsystems
- RAW Learn and Replay
- Universal RX Slots
- RF Analyzer and Noise Gate
- MQTT and Home Assistant Discovery
- REST API, WebUI, OTA and Backup/Restore

HCS200/HCS300 support has been removed completely from the firmware.
