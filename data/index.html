MAINTENANCE

System

Firmware update

Upload the PlatformIO firmware.bin. Only the firmware partition is updated; LittleFS configuration and RF slots remain untouched.

Backup

Download one backup containing the configuration and all saved TX slots. The file contains WiFi and MQTT credentials; store it securely.

Download backup

Restore backup

Restoring replaces the current configuration and TX slots, then restarts the bridge. Only OpenRF .orfbackup files are accepted.

Do not disconnect power during firmware update or backup restore.

PROJECT INFORMATION

About

OPEN SOURCE RF GATEWAY & ANALYZER

OpenRF Platform

A compact RF gateway and analyzer for ESP8266 and CC1101 with precise RAW Learn/Replay, protocol-aware RX events, WebUI, REST API, MQTT, Home Assistant Discovery, OTA and backup/restore.

Built for ESP8266 on purpose: to give the slightly dated but still capable boards sitting in drawers a useful second life.
