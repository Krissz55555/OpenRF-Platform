RF tuning session

How tuning works: applying a detected carrier starts a 15-minute TUNED session for that radio. RX Slot and RAW Learn store the current Operating frequency during this window. Temporary TX/scanner retunes return to the current Operating frequency. When the countdown reaches 00:00, or when you press Restore Default, the radio returns to its Default band frequency. A reboot also starts from Default.

PROJECT INFORMATION

About

OPEN SOURCE RF GATEWAY & ANALYZER

OpenRF Platform

A compact and powerful RF gateway and analyzer for ESP32-S3 and CC1101. It provides precise RAW Learn/Replay, protocol-aware RX events, RF Analyzer, WebUI, REST API, MQTT, Home Assistant Discovery, OTA updates and configuration backup/restore.

V2 beta platform: dual-core operation, PSRAM-aware memory, the V2 Protocol Engine and non-exclusive RF Analyzer. Bidirectional RAW RF Slots provide TX replay and UNKNOWN RAW receive matching. SX1276 LoRa hardware detection is supported; RF-engine integration is pending.
